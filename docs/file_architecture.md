# 文件架构表

路径相对于项目根目录。运行目录中的尖括号表示由程序填写的标识。

| 路径 | 文件或数据 | 写入责任 | Git 管理 |
|---|---|---|---|
| `AGENTS.md`、`README.md` | AI 接手规则、项目入口 | 项目维护 | 跟踪 |
| `docs/` | 架构、开发规范、操作说明 | 对应文档维护 | 跟踪可提交文档 |
| `script_download/<product>/` | 产品下载及下载验收脚本 | 数据获取 | 跟踪代码 |
| `data_raw/<product>/` | 原始产品文件和源归档 | 授权下载任务 | 忽略 |
| `config/` | 参数、表契约、敏感性矩阵 | M0 | 跟踪说明，运行配置留在本地 |
| `metadata/runs/<run_id>/` | 冻结配置、协议记录、输入与运行清单 | M0、M1、工作流，按文件分工 | 忽略，随运行归档 |
| `workflow/` | 阶段入口、依赖、续跑、发布控制 | 工作流维护 | 跟踪 |
| `src/fdwt/stages/<stage>/` | 科学处理、统计分析和复核代码 | 对应阶段 | 跟踪 |
| `tests/` | 自动化测试、样本生成代码 | 对应阶段及工作流维护 | 跟踪脚本和说明 |
| `data/interim/<run_id>/<stage>/<attempt_id>/` | 缓存、解压副本、待校验表、失败现场 | 本次阶段尝试 | 忽略 |
| `data/frozen/<run_id>/` | 按协议命名的阶段交接数据 | 产物所属阶段 | 忽略，随运行归档 |
| `logs/download/<product>/` | 下载、续传和异常日志 | 数据获取 | 忽略 |
| `logs/<run_id>/<stage>/<attempt_id>/` | 执行、错误和输入审计日志 | 本次阶段尝试 | 忽略，随运行归档 |
| `logs/deviation_log.csv` | 经审核的跨运行协议偏离台账 | M0／M10 | 忽略，随运行归档 |
| `outputs/<run_id>/{tables,figures,models,reports}/` | 可交付表、图、模型、质量与复核报告 | 产物所属阶段 | 忽略，随运行归档 |

## 阶段目录速查

以下目录都在 `src/fdwt/stages/`。完整依赖和协议表名以 FD-WT v1.3.1 技术手册与工程规格为准。M7 的 Q1／Q2 可在 M6 前执行，Q3 需接入 M6 暴露表。M8 按预设门槛执行，路线一可独立运行。

| 阶段 | 目录 | 主交接对象 |
|---|---|---|
| M0 | `m00_protocol` | 参数、表契约和协议冻结记录 |
| M1 | `m01_source_audit` | 文件清单、变量映射与放行记录 |
| M2 | `m02_preprocess` | 日历、日尺度和候尺度基础表 |
| M3 | `m03_support_climatology` | 掩膜、物候、气候态与可分析格点候 |
| M4 | `m04_event_catalog` | 闪旱候选审计与全量事件库 |
| M5 | `m05_recovery_precip` | 恢复轨迹、极端降水接续与分支标签 |
| M6 | `m06_exposure` | 植被年值、前期暴露与暴露簇 |
| M7 | `m07_route1` | Q1–Q3 风险集、分析数据和效应表 |
| M8 | `m08_route2` | 三出口数据与建模门槛判定 |
| M9 | `m09_robustness` | 跨产品匹配和敏感性结果 |
| M10 | `m10_review` | 样本流、独立复核记录和论文产物 |
